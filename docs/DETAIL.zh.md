# DeepSeek 对话

DeepSeek Harness Web GUI 里的一个专注的 DeepSeek 聊天客户端：左侧对话列表、
中间的流式 Markdown 回答、底部一个输入区。它用你自己的 Key 在浏览器里直连
[deepseek-ai/chat-demo](https://github.com/deepseek-ai/chat-demo) 的
Anthropic 兼容 Messages API，数据全部保存在 `localStorage`。

![面板：左侧对话列表、流式回答与输入区](preview.svg)

## 回答

- 流式回复，可停止；首个 token 出来前显示三点等待态；错误在回答内就地提示。
- Markdown 带代码高亮与复制按钮；KaTeX 数学公式与 Mermaid 图表（CDN 懒加载，
  失败时公式回退源码、图表回退代码视图）。
- 思考强度 关 / 低 / 高 / 最高，推理过程以可折叠时间线呈现。
- 服务端联网搜索与阅读链接：编号引用、网页数胶囊，以及边生成边更新的抽屉
  （实际跑了哪些搜索词、每条结果、打开了哪些页面）。
- 用户消息可 **编辑消息** 并从该条重发；回答被截断时可 **继续生成**，
  用 assistant prefill 续写并追加到同一条；**重新生成** 保留旧回答，用
  `‹ 1 / 2 ›` 切换版本；每条回答可复制、可朗读（播放时显示动态波形）。

## 设置

- **验证**：用免费的 `GET /models` 检查 Key，三态：正在验证… → Key 可用 /
  具体失败原因。
- API 地址、模型、朗读音色，以及可选的 **位置信息**；位置会写入每次请求的
  `latest_reminder` 行。
- **数据管理**：导出所有历史对话为 JSON 备份（不含 API Key）；导入备份需确认，
  会覆盖本浏览器里的历史；删除全部对话需二次确认。

## 文件与语音

- 拖入、粘贴或选择文件：图片与文档经 Files API 上传，由模型直接阅读，没有独立
  OCR 步骤。
- 麦克风最长录 110 秒后转写，沿用原版的「录音中 / 结束录音并转写 / 正在转写，
  点击取消」等状态文案，权限失败等错误就地提示。

## 隐私

Key 只发往你配置的 API 地址（`x-api-key`，验证时额外用一次 Bearer 请求
`/models`）。对话、设置与文件 id 保存在本浏览器 `localStorage`；上传的文件
留在 API 服务端；导出的备份不包含 Key。

完整能力表与已知限制见 [README](../README.md)（英文）。
